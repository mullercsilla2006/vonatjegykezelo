# vonatjegykezelo
This is a university project developed for the Basics of Programming 2 course at BME.

Note: The detailed software documentation source code comments, and input files are in Hungarian as per university requirements, but the codebase follows standard object-oriented principles.

Note on provided tools: The memtrace.h memory leak detector and the provided gtest testing framework headers are educational tools supplied by the Budapest University of Technology and Economics (BME).
